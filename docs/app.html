Quantum Tracker é uma plataforma completa de rastreamento inteligente desenvolvida pela FECART Labs, projetada para aplicações em segurança, pesquisa e robótica.

✨ Principais recursos

  • 🎯 Detecção de pessoas em tempo real — YOLOv8 + ByteTrack com IDs estáveis por Re-ID visual
  • 👁️ Reconhecimento facial — InsightFace para identificação biométrica persistente com banco de dados
  • 🤖 Controle robótico — Integração com ESP32/robôs reais via serial ou Wi-Fi (modo simulador também disponível)
  • 🖐️ Gestos manuais — MediaPipe Hands com classificador SVM treinável pelo próprio usuário
  • 🧠 IA conversacional — Chat integrado com Google Gemini para análise de cenas e eventos
  • 🗣️ Reconhecimento de voz — Comandos de voz em tempo real para controle do sistema
  • 📊 HUD tático — Overlay monochromático estilo militar com trilha de trajetória e histórico
  • 💾 Banco de dados SQLite — Histórico completo de sessões, eventos e identidades

Dados seguros

O Quantum Tracker é um aplicativo local e offline-first. Todos os dados de rastreamento, reconhecimento facial e histórico são armazenados exclusivamente no dispositivo do usuário em um banco de dados SQLite local.

Dados coletados

  • 📷 Imagens de câmera — processadas localmente, nunca enviadas
  • 🗃️ Embeddings faciais — armazenados localmente em formato criptografado
  • 🤖 Comandos de voz — processados localmente via SpeechRecognition
  • 🧠 Prompts do Gemini — enviados para a API Google apenas quando o chat IA está ativo

Nenhum dado é compartilhado com terceiros. A chave de API do Gemini é armazenada localmente e nunca transmitida para nossos servidores.

🚀 Passo a passo

    Baixe o Quantum Tracker

    Clique no botão abaixo para baixar o arquivo ZIP com todos os arquivos do projeto.

    Instale o Python 3.11+

    Acesse python.org e instale a versão mais recente. Marque "Add Python to PATH" durante a instalação.

  3. 3
    Extraia e instale dependências

    Abra o terminal na pasta extraída e execute:

  4. 4
    Execute o aplicativo

    Inicie o Quantum Tracker com:

  5. 5
