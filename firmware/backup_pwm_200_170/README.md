# Retorno ao PWM 200/170

Cópia do firmware gravado e observado pelo usuário em testes breves de rodas
suspensas em 16/09/2026, antes do aumento para 240/204. Isso não comprova
alinhamento ou velocidade sob carga no chão.

Para voltar, grave `backup_pwm_200_170.ino` ou o HEX correspondente no Arduino
UNO, com motores sem alimentação. Nenhum fio ou jumper precisa ser alterado.
